# ALEM WIND
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
HTML, CSS, JavaScript без фреймворка; MapLibre GL JS. Отчёты формирует существующий локальный Python-сервис HackAlem.

## Users
Энергетик, исследующий почасовой прогноз двух турбин возле Астаны. Оценщики продукта проверяют сценарий на демо.

## Product Purpose
Выбрать турбину, исследовать час на горизонте 24/48 часов, сравнить нормализованную мощность и ветер, получить воспроизводимый научный отчёт.

## Capabilities and Constraints
Источники synthetic, demo, backtest. Мощность только p.u.; номиналы неизвестны. Фактические данные февраля отсутствуют. В локальном репозитории есть demo, нет backtest. Координаты из кейса не подтверждены. Нет направления или пространственного поля ветра. Исходная папка используется только как справочный контекст и источник чтения.

## Brand Commitments
Русский интерфейс, заданная зелёно-белая палитра, системный sans-serif, постоянные зелёная T1 и синяя T2. Географическая карта, а не схема.

## Accessibility & Inclusion
Клавиатурный выбор времени и объектов, цели 44 px, reduced motion, мобильная нижняя панель, работа данных без WebGL.
