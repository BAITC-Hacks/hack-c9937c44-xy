# ALEM WIND: визуальная система

Источник: `HackAlem/OPEN_DESIGN_PROMPT.md`, строки 14–19. Цвета пересчитаны из заданных sRGB без изменения визуального направления.

```css
:root {
  --bg: oklch(97.23% 0.0063 138.6);
  --surface: oklch(100% 0 0);
  --fg: oklch(27.30% 0.0303 167.3);
  --muted: oklch(52.77% 0.0255 163.7);
  --border: oklch(91.26% 0.0129 151.4);
  --accent: oklch(47.10% 0.0873 166.3);
  --font-display: 'Segoe UI', system-ui, sans-serif;
  --font-body: 'Segoe UI', system-ui, sans-serif;
  --font-mono: 'Cascadia Code', Consolas, monospace;
}
```

- Светлый зеленоватый фон, белые рабочие панели, тонкие разделители.
- Системный sans-serif для утилитарного интерфейса; моноширинные табличные числа.
- Зелёный акцент для выбранного действия, зелёная T1 и синяя T2 для данных, форма и штрих дополняют цвет.
- Отступы кратны 4/8 px; радиусы 12–16 px; плотность служит операторскому сценарию.
- Карта доминирует; панель и время остаются читаемыми на непрозрачных поверхностях.
